# Gomoku — 五子棋

纯原生 JavaScript 实现的五子棋（Gomoku）对弈游戏，零依赖，打开即玩。

## 功能特性

- **15×15 标准棋盘** — 带有星位标记和网格线渲染
- **双人本地对弈** — 黑方先行，轮流落子
- **胜负判定** — 自动检测五连及平局（棋盘填满）
- **落子动效** — 棋子放置伴随缩放动画，最后一步高亮标记
- **步数历史** — 显示最近 40 步走棋记录，支持滚动回溯
- **悔棋** — 撤销上一步落子，回到己方回合
- **比分追踪** — 累计黑白双方胜场，支持重置比分
- **Toast 通知** — 胜负/重置操作的系统级轻提示
- **响应式布局** — 640px 断点适配移动端，棋盘自动缩放

## 技术要点

- **无框架依赖** — 全部使用原生 DOM API 和 CSS Grid 实现
- **CSS Grid 棋盘** — 15×15 网格配合伪元素绘制经纬线，无须 Canvas
- **方向向量扫描** — 四方向（水平、垂直、主对角线、副对角线）线性扫描判定五连
- **数据驱动渲染** — 棋盘状态与 DOM 分离，操作基于 board 二维数组后再更新视图
- **IIFE + 命名空间** — JS 文件通过 IIFE 隔离作用域，全局暴露 `GamePage`、`Utils`、`Toast`

## 快速开始

直接用浏览器打开 `index.html` 即可开始游戏，无需构建工具或服务器。

如需本地服务器预览：

```bash
npx serve .
```

## 浏览器兼容

支持所有现代浏览器（Chrome、Firefox、Safari、Edge）。
